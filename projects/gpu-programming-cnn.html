GPU Programming - Speed up a Convolutional Neural Network

Implemented convolutional neural networks using CUDA for parallel processing, optimizing performance through GPU acceleration and memory management techniques.

This project focused on leveraging the parallel processing capabilities of GPUs to accelerate convolutional neural network operations. By implementing custom CUDA kernels and optimizing memory access patterns, significant performance improvements were achieved compared to CPU-based implementations.

The implementation included efficient handling of convolution operations, pooling layers, and activation functions, demonstrating the power of GPU computing for deep learning applications.
