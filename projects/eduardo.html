Eduardo – MHacks 16 x Google

AR • Unity • C# • Computer Vision • Machine Learning

Overview

Eduardo is an Augmented Reality (AR) educational guide designed to teach users how to perform various actions through interactive, step-by-step instructions. Built for the Google x MHacks 16 hackathon.

Core Concept

Eduardo serves as a virtual assistant that appears in the real world through AR technology, guiding users through complex tasks with visual cues, voice instructions, and interactive demonstrations.

Key Features

  • AR Visual Guidance: Real-time visual overlays showing exactly where and how to perform actions
  • Step-by-Step Instructions: Breaking down complex tasks into manageable, sequential steps
  • Interactive Feedback: Real-time assessment of user actions with corrective guidance
  • Multi-Modal Learning: Combining visual, auditory, and kinesthetic learning approaches
  • Task Adaptation: Customizing instruction complexity based on user skill level

Technical Implementation

Built using Unity with AR Foundation, incorporating:

  • AR Tracking: Advanced computer vision for real-world object recognition and tracking
  • 3D Modeling: Custom 3D assets for virtual assistants and instructional elements
  • Voice Synthesis: Text-to-speech for audio instructions and feedback
  • Machine Learning: Adaptive learning algorithms to personalize instruction

Hackathon Achievement

This project was developed during MHacks 16 sponsored by Google, competing against hundreds of other innovative solutions in the AR and education space.
