PrimeGPT – MHacks 16

NLP • ChatGPT API • Web Scraping • React • Node.js

Overview

PrimeGPT is an intelligent chatbot designed to answer queries about specific products on Amazon. Built for MHacks 16, it combines natural language processing with real-time web scraping to provide accurate, product-specific information.

Core Functionality

The chatbot can answer detailed questions about Amazon products by:

  • Product Research: Scraping current product information from Amazon
  • Intelligent Responses: Using NLP to understand and answer specific queries
  • Real-time Data: Providing up-to-date pricing, reviews, and specifications
  • Contextual Understanding: Maintaining conversation context for follow-up questions

Technical Implementation

Built using modern web technologies:

  • Frontend: React for interactive chat interface
  • Backend: Node.js for API handling and web scraping
  • NLP Engine: Integration with ChatGPT API for intelligent responses
  • Data Processing: Real-time Amazon data scraping and parsing
  • State Management: Conversation history and context tracking

Key Challenges Solved

  • Dynamic Data: Handling constantly changing product information
  • Query Understanding: Accurately interpreting user questions about products
  • Response Accuracy: Ensuring information is current and correct
  • User Experience: Creating an intuitive chat interface

Hackathon Achievement

Developed during MHacks 16, this project demonstrates the integration of AI language models with e-commerce data to create intelligent, context-aware shopping assistants.
