Tiny NeRF Model

Implemented Neural Radiance Fields (NeRF) for 3D scene reconstruction from 2D images, using neural networks to generate novel views and depth maps.

This project involved implementing Neural Radiance Fields, a cutting-edge technique for 3D scene reconstruction from multiple 2D images. The implementation used neural networks to learn the volumetric scene representation, enabling the generation of novel views and depth maps from arbitrary camera positions.

The project demonstrated the power of neural rendering techniques for computer vision and graphics applications, showcasing how machine learning can be used to reconstruct and visualize 3D environments from limited 2D input data.
