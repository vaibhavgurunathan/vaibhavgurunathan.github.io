Tiny NeRF Model

I implemented a small NeRF (Neural Radiance Fields) pipeline for 3D scene reconstruction from a set of 2D images — the idea is the network learns a volumetric representation so you can render new views. This was a course project; I will add which class, what dataset we used, and what the results looked like when I have the details in front of me.
