4-Function Calculator on FPGA

Verilog • FPGA • Digital Logic • State Machines

Overview

A complete 4-function calculator implemented on an FPGA board using Verilog. This was the culminating project for my Computer Logic class at the University of Michigan, requiring deep understanding of digital systems and hardware programming.

Why This Project Was Challenging

While implementing a calculator in a high-level programming language is straightforward, this project required implementing all operations at the bit level using digital logic gates and registers. No built-in arithmetic operations were allowed - everything had to be built from fundamental logic gates.

Technical Implementation

Addition & Subtraction

  • Bit-level Operations: Custom addition circuit with carry propagation
  • Overflow Handling: Detection and display of overflow conditions
  • 4-digit Support: Handling arithmetic across multiple digits

Multiplication

  • Booth's Algorithm: Implementation of Booth's multiplication algorithm
  • Bit Manipulation: Complex bit shifting and addition operations
  • Efficiency Optimization: Minimizing gate usage and propagation delay

Division

  • Custom Division Logic: Bit-by-bit division implementation
  • Remainder Calculation: Proper handling of division remainders

State Machine Design

The calculator used a sophisticated state machine that:

  • Clock Synchronization: All operations triggered by clock edges
  • Input Processing: Handling button presses and number entry
  • Operation Sequencing: Proper sequencing of arithmetic operations
  • Display Management: Updating LED displays with results

Hardware Constraints

  • FPGA Limitations: Working within the constraints of the development board
  • Resource Optimization: Efficient use of logic gates and registers
  • Timing Considerations: Ensuring proper signal propagation delays
  • Debug Challenges: Limited debugging tools compared to software development

Key Achievements

This project demonstrated mastery of:

  • Digital logic design principles
  • Hardware description languages (Verilog)
  • State machine implementation
  • Low-level computer architecture
  • Problem-solving in constrained environments
