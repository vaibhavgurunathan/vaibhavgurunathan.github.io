Machine Learning Image Classifier

Python • TensorFlow • Keras • OpenCV

Overview

A deep learning project that classifies images using Convolutional Neural Networks (CNNs). Trained on the CIFAR-10 dataset, achieving 90% accuracy in recognizing 10 different object categories.

Key Features

  • Image Classification: Recognizes 10 object categories (airplane, automobile, bird, etc.)
  • Model Training: Custom CNN architecture with data augmentation
  • Performance Metrics: 90% accuracy on test dataset
  • Web Interface: Flask-based web app for easy image upload and classification
  • Model Optimization: Techniques for faster inference and reduced model size

Technical Implementation

Built using TensorFlow and Keras frameworks. The CNN architecture includes multiple convolutional layers, max pooling, dropout for regularization, and dense layers for classification. Data preprocessing included normalization and augmentation techniques.
