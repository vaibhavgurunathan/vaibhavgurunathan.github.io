StudyStream - MHacks 2024

React • Node.js • Computer Vision • Vector Database • Text-to-Speech

Overview

StudyStream was my hackathon submission for MHacks 2024. It's an AI-powered educational tool that converts text content into engaging, synchronized video lectures with visuals and audio narration.

How It Works

The frontend takes input either as a file or copy/pasted text along with desired video length. It sends this to the backend which performs several sophisticated AI operations:

  1. Text Segmentation: Splits the text into logical sections based on the requested video length
  2. Image Selection: Scrapes Google Images and uses computer vision to find the most relevant image for each concept
  3. Vector Search: Converts image descriptions to vectors and queries a vector database to find the best matches
  4. Audio Generation: Uses text-to-speech conversion to create narration for each section
  5. Video Assembly: Combines images, bullet points, and audio into a cohesive video

Technical Implementation

The system leverages multiple AI technologies:

  • Computer Vision: For image-to-text conversion and analysis
  • Natural Language Processing: For text segmentation and bullet point generation
  • Vector Databases: For efficient similarity search of image descriptions
  • Text-to-Speech: For high-quality audio narration
  • Video Processing: For combining multimedia elements
