Music Genre Classifier

Python • TensorFlow • Machine Learning • Audio Processing

Overview

A machine learning project that classifies music into different subgenres within metal music using audio feature extraction and neural networks.

Technical Approach

The classifier uses audio signal processing techniques to extract meaningful features from music files, then applies machine learning algorithms to categorize the music into specific subgenres.

Features

  • Audio Feature Extraction: MFCCs, spectral contrast, chroma features, and rhythmic patterns
  • Neural Network Architecture: Multi-layer perceptron with dropout and regularization
  • Genre Classification: Distinguishes between various metal subgenres
  • Performance Evaluation: Accuracy metrics and confusion matrix analysis

This project is currently being updated with more detailed information and results.
