Teaching My First Class

Hi Everyone,

This semester, I was an instructor assistant for ROB 330: Simulataneous Localization and Mapping. This was one of the hardest classes in the robotics program given the complex coding and that they had to get the code to work on an actual robot. The robot made it so much more confusing compared to a general coding assignment. Even if the code worked, the robot could have it's own problems and mislead the students into thinking their solution was wrong.

In this class, the curriculum was still being developed as the class was progressing. Since I had taken the class, there was a lot of change and the full code wasn't ready. To help set up the class and ensure that everything was ready, I (along with the other IA and the GSI) worked to fix all the changes and prep everything for the students.

Given how complex the class was, our office hours were constantly flooded with students. All three of us spent countless hours helping students both in and out of class. Before demo days, where the students had to run their code on the robot to be graded, the three of us would hold oand end at 10 pm officially. Not once had the office hours ended at 10pm. The earliest I remember getting out was for one of the easier projects at 1:30am the day the project was due. We would be helping students the entire time, helping them understand the code and debug their solutions.
